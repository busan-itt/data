## 해석 기준과 확인 사항

- 기간 조건은 두 자료의 작업 시각이 2024-11-01 이상 2026-03-01 미만이며, 가장 가까운 시각 차이가 달력 기준 3개월 이내인 것입니다. 기간 일치는 직접 환적이나 같은 운송 회차의 확정을 뜻하지 않습니다.
- ERROR 25,367행은 시각 차이 3개월 초과 15,133행과 분석기간 내 DGT 작업 시각 없음 10,234행입니다. 최종 미해결 조회 실패는 0건입니다.
- **현재 CSV는 수집 당시 판정 그대로 보존했습니다.** BPT는 접안 시각까지 비교에 포함했으므로, 실제 반입·반출 시각만으로 재검토하면 838행(730개 번호)은 기간 재검토 대상입니다. 환적 물동량 집계 전에 회차·이동 방향·환적 Class·차량·전배 여부를 검토해야 합니다.
- 대상 번호는 환적 표시로 선정했지만 해당 번호의 다른 회차도 수집했습니다. 기간 통과 결과에 TI/TX/TL 이외 Class도 포함되어 있습니다.
- 비용·홀드·냉동·재조작 등은 조회 시점의 응답일 수 있습니다. 빈 항목·공개 접근 제한은 없음 또는 0을 뜻하지 않습니다.
- 로컬 상태·로그·설명에 남은 `C:/work/...` 경로는 당시 기록입니다. 저장소 기준 실제 파일 위치와 구분하세요.

## 다운로드와 인증정보

CSV와 SQLite 파일은 Git LFS로 관리합니다. 일반 Git 복제 후 `git lfs pull`을 실행하면 실제 대용량 파일을 받을 수 있습니다.

폴더 구조와 수집 파일을 보존하되, **카카오 인증파일 `kakao_credentials.dpapi`는 제외**했습니다. 저장소에 인증정보를 추가하지 마세요. 파일 수·용량 및 주요 파일 해시는 `UPLOAD_MANIFEST.json`을 참고하세요.


## DGT 자부두 환적 명세 조회 (2026-10-21 완료)

dgt.csv의 Class TI/TX/TL 고유 번호 169,773개에서 기존 HJNC/BPT 조회 번호 64,494개를 제외한 105,279개를 모두 조회했습니다. 번호는 한 번씩 조회하고 방문 point별 회차는 구분했습니다.

DGT_SELF_TS.csv 203행(203번호), 검토.csv 2,366행(2,236번호), 비해당.csv 128,613행, ERROR.csv 0행입니다. 한 번호가 여러 회차에 속할 수 있어 파일별 번호 수는 합산하지 않습니다. 최종 저장검증 verified=true, target_complete=true이며 체크포인트 미반영분은 없습니다.

SELF는 같은 point의 선박 반입·반출 S→S, 서로 다른 모선, 완료 조건을 충족하고 반입·반출이 2024-11-01 이상 2026-03-01 미만이며 간격이 3개월 이내인 명세입니다. 원본 기준 시각과의 3개월 조건도 적용했습니다. 원본 도로 회차와 동일 회차 확정 또는 DGT 전체 물동량을 의미하지 않습니다. 상세 응답은 조회 시점 정보일 수 있어 과거 지연 원인으로 단정하지 않습니다.

결과와 원문 기록은 PJ_DATA/조회결과/DGT_자부두환적 및 PJ_DATA/조회기록/DGT_자부두환적에 보관합니다. 코드는 크롤링 코드/DGT의 dgt_self_ts_job.py와 의존 dgt_spec_job.py이며 실행설명.txt를 참고합니다. --prepare는 대상 준비, --run은 미처리 번호 조회, --export-only는 새 조회 없이 CSV 저장입니다. 일반 오류는 총 3회, 인터넷 단절은 별도 대기하며 중복 실행을 차단합니다. 인증 정보는 포함하지 않습니다.
