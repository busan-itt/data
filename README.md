# HJNC 2025 Gate In/Out 데이터

`DATA` 폴더에는 2025년 월별 Gate In/Out 원본 CSV와 연간 한글 변환본만 저장합니다. 모든 CSV는 Git LFS로 관리합니다.

- `HJNC_2025_MM.csv`: API에서 수집한 월별 원본 데이터입니다. `MM`은 `01`부터 `12`까지입니다.
- `HJNC_2025_annual.csv`: 1월부터 12월까지의 한글 변환본을 월 순서대로 합친 연간 데이터입니다. 총 1,372,091건입니다.

한글 변환본의 주요 컬럼 예시는 `컨테이너번호`, `반입시간`, `반출시간`, `차량번호`, `선사`, `조회일자`입니다.
